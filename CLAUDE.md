# What is the project
The DCUniversity project is a teaching enviroment of some subjects. The first goal, is an website that serves animated slides of python, but in the future, it will also have interactive lessons.

# What should the main file structure be?
In the main folder, only the LICENSE, README.md and CLAUDE.md. The /docs folder have all the instructions you have to follow to build the website or the slides. The src/ folder will be the only folder you will be allowed to access. You shouldn't access anything else. If you need to access other folders, ask for permission.
